# AI Adelaide - Missed Call Calculator

A free Chrome extension that helps small business owners understand the real cost of missed phone calls.

## What it does

- Simple calculator: calls missed × average job value × conversion rate = $/year lost
- Designed for tradies, service businesses, and SMBs
- Clean, minimal popup UI

## Installation

1. Download/clone this repository
2. Go to chrome://extensions/
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the `calculator-extension` folder
